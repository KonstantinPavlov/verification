# План на первую итерацию

## Сборка и проверка проекта

Использовать `github/workflows`
Минимальное покрытие общего кода не менее 60%

## Основные моменты

Минимум флагов для запуска приложений
Основные настройки через `.yaml` файлы

## Основные пакеты 

### Пакет `core `

Концепт DI контейнера - управляющего циклом работы ресурсов приложения 

### Пакет `logger` 

Реализация общего стиля логирования проекта на основе `log/slog` с возможностью добавления дополнительных хэндлеров 

### Пакет `http_server`

Веб сервер `labstack/echo/v5`
Мидл с ендпоинтом метрик в формате Prometheus `/metrics`
Простейший ендпоинт `/health`

### Пакет `kafka` 

Основа - `confluent-kafka-go/v2/kafka`

#### Consumer 

Работает в двух режимах 
- Single 
- Batch 

Слушает и логирует rebalance события 
Имеет минимальный набор метрик по своей работе

#### Producer

Простейший продьюсер с синхронной и асинхронной отправкой событий
